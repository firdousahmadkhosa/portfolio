# Firdous Ahmad Portfolio

Personal portfolio website for Firdous Ahmad, a Senior Full-Stack and AI Engineer specializing in multi-tenant SaaS, Elasticsearch, AWS, cloud infrastructure, and applied AI.

## Files

- `portfolio.html` - Portfolio website
- `logo.jpeg` - Profile avatar image

## Run Locally

Open the folder through a local web server:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000/portfolio.html](http://localhost:8000/portfolio.html).

## Deploy With GitHub Pages

1. Rename `portfolio.html` to `index.html`.
2. Keep `logo.jpeg` in the same folder as `index.html`.
3. Push both files to the `main` branch of a GitHub repository.
4. Open **Settings > Pages** in the repository.
5. Select **Deploy from a branch**, choose `main` and `/ (root)`, then click **Save**.
6. Open the GitHub Pages URL provided by GitHub.

## Contact Form

The contact form uses FormSubmit to send enquiries to `firdous.ahmad.dev@gmail.com`. The website must be opened through an HTTP/HTTPS URL, such as GitHub Pages; it will not work when opened directly as a `file://` HTML page.

Confirm the FormSubmit activation email after the first submission.
